# __a)__ Apassi. Asenna Apache 2 käsin. Weppisivun tulee näkyä palvelimen etusivulla. Sivun tulee olla tavallisen käyttäjän muokattavissa, ilman root- tai sudo-oikeuksia.
- aloitin tehtävän asentamalla apachen.
- ensin komennolla: sudo apt update ja sitten sudo apt install apache2 <img width="2936" height="348" alt="image" src="https://github.com/user-attachments/assets/6bcaf302-467f-4e45-8ed4-a3f24a327828" />
- tämän jälkeen painoin yes

- Sitten tarkistin että apache2 oli ladattu komennolla: systemctl status apache2 <img width="2008" height="504" alt="image" src="https://github.com/user-attachments/assets/4c4af922-1853-441d-b394-0265820ae09e" />
- tulos näytti active, eli kaikki on kunnossa.

- Tämän jälkeen teen käyttäjän oman kotisivun
- aloitin tekemällä uuden kansion komennolla: mkdir -p ~/publicsite
- Sitten tein sinne tekstitiedoston komennolla: nano ~/publicsite/index.html
- Laitoin tiedostoon uuden sisällön

- Tämän jälkeen annoin apachelle oikeuden lukea sivun komennoilla:
- chmod ugo+x ~/
- chmod ugo+x ~/publicsite
- chmod ugo+r ~/publicsite/index.html

- Tämän jälkeen tarkistin oikeudet komennoilla: ls -ld ~ ~/publicsite ja ls -l ~/publicsite/index.html <img width="2008" height="416" alt="image" src="https://github.com/user-attachments/assets/ee0ae23b-a689-4f50-8691-fe807c9dbb06" />

- Tämän jälkeen tein apachelle konfiguraation komennolla: sudo nano /etc/apache2/sites-available/publicsite.conf
- Ja lisäsin sinne sisällön: <img width="2422" height="352" alt="image" src="https://github.com/user-attachments/assets/40d46ca0-abc1-40e7-bb6a-a9a5a40b580c" />
- Tämän jälkeen otin sivuston käyttöön komennolla: sudo a2ensite publicsite.conf
- Sitten testasin konfiguraation komennolla: <img width="2446" height="220" alt="image" src="https://github.com/user-attachments/assets/cc44e73e-3133-4612-8b3b-071191f6b65d" />
- Testissä lukee syntax ok eli se toimii.

- Tämän jälkeen latasin apachen uudelleen komennolla: sudo systemctl reload apache2

- Sitten testasin toiminnan menemällä osoitteeseen http://omanpalvelimenip <img width="2446" height="292" alt="image" src="https://github.com/user-attachments/assets/8d80a0b1-5e4e-43fb-bae3-4572fbbe8f56" />
