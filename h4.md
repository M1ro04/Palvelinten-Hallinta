# __a)__ Räpylä. Asenna itse valitsemasi demoni käsin. Jokin muu kuin tunnilla tai kotitehtävissä aiemmin asennettu, eli ei apache, ngninx eikä openssh-server. Kuten aina, testaa lopputulos.
- tehtävään valitsin demoniksi postgreSQL
  
- Aloitin tehtävän antamalla komennot: sudo apt update ja sudo apt-get -y install postgresql

- Sitten tarkistin palvelun komennolla: systemctl status postgresql <img width="2032" height="318" alt="image" src="https://github.com/user-attachments/assets/3b1893a0-0be1-40e2-af4f-74ff6f056cd2" />
- Näkyy active, joten kaikki on kunnossa.

- Tämän jälkeen aloitin postgreSQL komennolla: sudo systemctl start postgresql

- Sitten tein käyttäjän komennoilla: sudo -u postgres createdb miro ja sudo -u postgres createuser miro

- Tämän jälkeen testasin postgreSQL toiminnan komennolla: psql <img width="2032" height="760" alt="image" src="https://github.com/user-attachments/assets/3474494f-762d-405e-861b-9f1b88fdc39e" />
- Toimii!
